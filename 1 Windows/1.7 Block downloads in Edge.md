Stops users and attackers pulling executables down with the browser. Edge (and Chrome) have one policy for this, `DownloadRestrictions`. It works on file risk, not on a list of extensions:

| Value | Effect |
|---|---|
| 0 | No restrictions |
| 1 | Block dangerous downloads (most `.exe`, `.msi`, scripts) |
| 2 | Block potentially dangerous or unwanted downloads |
| 3 | **Block all downloads** |
| 4 | Block malicious downloads (SmartScreen verdict only) |

Use **1** for normal machines and **3** on servers and domain controllers, where nobody should be downloading anything.

> [!warning] Do not use `ExemptDomainFileTypePairFromFileTypeDownloadWarnings` for blocking
> That policy **removes** the warning for the listed file types and domains, so listing `exe` and `msi` with `*` makes them download without a prompt.

## Check

On a machine, open `edge://policy` and look for `DownloadRestrictions`, or:

```powershell
Get-ItemProperty 'HKLM:\SOFTWARE\Policies\Microsoft\Edge' -ErrorAction SilentlyContinue | Select-Object DownloadRestrictions, ExemptDomainFileTypePairFromFileTypeDownloadWarnings
```

## Do: GPO

```powershell
$gpo = 'Browser download restrictions'
$dn  = (Get-ADDomain).DistinguishedName
New-GPO -Name $gpo | Out-Null
Set-GPRegistryValue -Name $gpo -Key 'HKLM\SOFTWARE\Policies\Microsoft\Edge'  -ValueName DownloadRestrictions -Type DWord -Value 1
Set-GPRegistryValue -Name $gpo -Key 'HKLM\SOFTWARE\Policies\Google\Chrome'   -ValueName DownloadRestrictions -Type DWord -Value 1
New-GPLink -Name $gpo -Target $dn -LinkEnabled Yes

# Servers and DCs: block everything
$gpo2 = 'Browser downloads blocked (servers)'
New-GPO -Name $gpo2 | Out-Null
Set-GPRegistryValue -Name $gpo2 -Key 'HKLM\SOFTWARE\Policies\Microsoft\Edge' -ValueName DownloadRestrictions -Type DWord -Value 3
New-GPLink -Name $gpo2 -Target "OU=Domain Controllers,$dn" -LinkEnabled Yes
```

## Do: one host

```powershell
$p = 'HKLM:\SOFTWARE\Policies\Microsoft\Edge'
New-Item $p -Force | Out-Null
Set-ItemProperty $p -Name DownloadRestrictions -Value 1 -Type DWord
Remove-ItemProperty $p -Name ExemptDomainFileTypePairFromFileTypeDownloadWarnings -ErrorAction SilentlyContinue
```

## Going further

The browser policy does not stop `curl`, `Invoke-WebRequest`, `certutil` or `bitsadmin`. To stop programs running from user folders at all, use AppLocker or Windows Defender Application Control with a rule that blocks `%USERPROFILE%\Downloads\*` and `%TEMP%\*`.

## Verify

Restart Edge, open `edge://policy`, click **Reload policies**: `DownloadRestrictions` shows your value with status OK. Try downloading a small `.exe`: it is blocked.

## Roll back

Remove the GPO link, or `Remove-ItemProperty 'HKLM:\SOFTWARE\Policies\Microsoft\Edge' -Name DownloadRestrictions`.
