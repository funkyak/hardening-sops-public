Back up, add an SSH key, change the password and turn off password login on VyOS (1.3 / 1.4). Every change uses `commit-confirm`, so if you lock yourself out the router undoes it on its own.

## 1. Back up

```
configure
save /config/backup-before-hardening.config
exit
show configuration commands
```

Copy the output of `show configuration commands` to your admin machine as well, or:

```bash
scp vyos@<router>:/config/backup-before-hardening.config ./vyos-$(date +%Y%m%d).config
```

## 2. Add your SSH key

Split your public key into its three parts: type (`ssh-ed25519`), key (`AAAA...`) and a name (`breakglass`).

```
configure
set system login user vyos authentication public-keys breakglass type ssh-ed25519
set system login user vyos authentication public-keys breakglass key AAAA...your-key-without-type-or-comment...
commit
save
exit
```

From a new terminal: `ssh -i ~/.ssh/breakglass vyos@<router>` must work before you go on.

## 3. Change the password

```
configure
set system login user vyos authentication plaintext-password 'new-long-password'
commit
save
```

VyOS stores it hashed. Check `show system login user` (in configure mode, `show system login`) for users you did not create and `delete system login user <name>`.

## 4. Password login off

```
configure
set service ssh disable-password-authentication
set service ssh listen-address <management-ip>
commit-confirm 5
```

Now, **from a new terminal**, log in with your key. If it works, go back to the first session and type:

```
confirm
save
```

If you cannot get back in, do nothing: after 5 minutes VyOS reboots onto the previous configuration.

> [!note] No per-user exception on VyOS
> `disable-password-authentication` applies to every user. If `gt` must log in to VyOS with a password, skip step 4 and limit SSH with `listen-address` and firewall rules instead.

## Verify

```bash
ssh -i ~/.ssh/breakglass vyos@<router> 'show version'                 # works
ssh -o PubkeyAuthentication=no vyos@<router>                          # Permission denied (publickey)
```

## Roll back

```
configure
load /config/backup-before-hardening.config
commit
save
```

To see recent commits: `show system commit`. To compare with one: `compare <n>` in configure mode.
